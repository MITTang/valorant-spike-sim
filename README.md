# Spike 仿真电路（SimulIDE）

《无畏契约》爆能器（Spike）实物模拟：STC89C52RC / Keil C51 固件 + SimulIDE 8051 仿真电路。
状态机：待机 → 长按 S2 满 4 秒充能下包 → 45.00 秒倒计时 → 长按 S3 拆包（半拆机制），超时未拆爆炸。

## 怎么启动（只有一个流程：长按 S2 满 4 秒）
1. 双击 `Spike_sim.sim1`。
2. 点工具栏**电源按钮**（那对圆形按钮里红色的）→ 右上角变绿「正在运行」。此时**待机**：LED 全灭、数码管灭。
3. **用鼠标按住「S2 下包」按键不放，数满 4 秒**（它接 P3.1）。
   - 松手太快 = 充能中断，LED 全灭、回到待机（这是代码里 `flag_split` 的逻辑，故意做的）。
   - 按住期间：每 500ms 依次点亮一个 LED（8 个灯 4 秒点亮完），按满 4 秒才真正下包。

> 已去掉原来那个“上电 3 秒自动下包”的演示版，现在只有长按才启动。

## 完整流程（严格按你 `spike.c`）
1. **待机**：`led_val = LED_OFF`（8 灯灭）、数码管灭、蜂鸣器静音。
2. **长按 S2（P3.1）满 4 秒充能下包**（`ST_CHARGING`）：
   - 按下 0.2 秒后蜂鸣器“滴滴”两声；
   - 每 500ms 依次点亮一个 LED（`led_mask()` 查 `on_tab`，从 P1.7 向 P1.0 逐个亮），亮灯不出声；
   - 中途松手：充能清零、LED 全灭、取消下包。
3. **充能满 4 秒 → 下包成功**：8 灯全亮 + 嘀一声，数码管 `45.00` 起步。
4. **45.00 → 00.00 精密倒计时**（10ms 精度）。滴答节奏按剩余时间分四档：
   `>22.5s → 1000ms`、`10~22.5s → 500ms`、`5~10s → 250ms`、`0.5~5s → 125ms`、`≤0.5s → 长鸣不停`。
5. **LED 脉冲**：每响一声 8 灯同步全亮（`LED_ON`），响完立刻熄灭。
   亮度由 PWM 控制：5ms 一周期、`LED_DUTY=2` 即 40% 占空比（改 3 更亮、1 更暗）。
6. **最后 10 秒**：数码管 200ms 亮 / 200ms 灭急促闪烁。
7. **长按 S3（P3.2）拆包 —— 半拆机制**：
   - 0~3.5 秒：LED 从头部逐个熄灭（8→4 个）；
   - **3.5 秒存档点**：嘀一声，此时松手进度保留，停在“前 4 个亮”；
   - 再按住 3.5 秒（4→0 个）即拆包成功；
   - 未到 3.5 秒松手：进度清零，回到脉冲待机；
   - 满 7 秒：倒计时停、蜂鸣器停、灯灭、数码管清空 + 嘀嘀两声。
8. **归零未拆 → 爆炸**：`00.00` + LED 全亮狂闪 2 秒 + 长鸣。

## 电路与代码的对应关系（这次已经对齐）
| 代码里的定义 | 电路里的接法 |
|---|---|
| `LED = P1`，`LED_ON=0x00` 低电平亮 | `+5V → 220Ω → LED 阳极`，阴极接 P1.x |
| `DU = P2.6` 段选锁存 | 74HC573-1 的 LE ← P2.6，Q0~Q7 → `pin_a..pin_g` |
| `WE = P2.7` 位选锁存，`pos_tab` 低有效 | 74HC573-2 的 LE ← P2.7，Q0~Q7 → `pin_commona..h` |
| `sbit K_PLANT = P3^1`（S2 下包） | Push-1「S2 下包」→ P3.1，另一端接地 |
| `sbit K_DEFUSE = P3^2`（S3 拆包） | Push-2「S3 拆包」→ P3.2，另一端接地 |
| `BEEP = P2.3` 低电平响 | AudioOut 蜂鸣器 → P2.3 |
| 段码 `seg[]` 共阴 | 8 位共阴数码管 |

## 沿用的老坑（改图别踩回去）
1. **EA 必须接 5V 母线（Rail）**。接普通 Fixed Voltage 会被读成低电平 → 选外部程序存储器 → PC 跑飞，日志报 `PC = 4096 / MCU stopped`。
2. **RST 接 5V**（模型里是低有效 `!rst`，接地 = 一直复位）。
3. 两片 573 和 MCU 的 Vcc 都要接 5V（Node 只有 3 脚，要串两级扇出）。
4. Node 只有 3 个引脚；**8 位数码管没有 dp 引脚**，段线只能接 a~g。
5. 固件 ≤ 4KB（MCS51 模型 prog=4096）；Keil 这里是评估版，代码上限 2KB。
